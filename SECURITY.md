# Security policy

This is an early local prototype with no backend, account system, or third-party runtime package dependencies. Please report suspected vulnerabilities privately to the repository owner rather than opening a public issue containing exploit details. A security contact must be configured when the GitHub repository owner is confirmed.

Before accepting external contributions, enable GitHub secret scanning and Dependabot alerts where available. Keep workflow permissions read-only unless a job needs more. Review dependency and workflow changes before merging.
